Token Usage 是**开源自托管**的 AI 编码 token 用量追踪：一个账号看所有采集端的用量与成本，
数据完全落在你自己的 Supabase 里。本节文档面向使用者与自部署者，提取上手所需的重点；
完整工程规范见 [GitHub 仓库 docs/](https://github.com/baiwumm/token-usage/tree/main/docs)。
