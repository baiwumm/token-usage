# Changelog

桌面端（`apps/desktop`，Windows NSIS 安装包 + tauri updater）的用户可见变更记录。
发版时在顶部新增一节，`## <版本号>` 行会被 release workflow 取作 GitHub Release
正文。

## 0.4.0

2026-11-12。会话筛选补齐项目与模型两维：来源 / 项目 / 模型三个下拉各自的选项按「时间窗 +
另外两个条件」计算，选定项目不会把自己的选项收窄；CSV 导出跟随筛选结果。设置新增「本机
数据」：一键在文件管理器里打开采集器的数据目录与日志目录。托盘右键菜单新增「今日 / 7D /
30D / 总计」周期切换，托盘上的用量行跟随所选周期，并与此前头部的周期筛选共享同一偏好。

## 0.3.1

2026-11-12。维护版本：修正「托盘图标未注册」提示的成因与恢复指引——真正的条件是任务栏
权限高于本应用（常见于由低权限程序或受限计划任务启动），不是「关闭 UAC 的 Windows」；
提示里直接写明用「以管理员身份运行」重启即可恢复。同时确认安装与升级**不再需要**给程序
文件手动调整完整性标签（此前文档里的兜底做法）。本版主要用于验证应用内更新链路。

## 0.3.0

2026-11-12。会话与分享（D11）：页头新增「会话」视图——本机采集的全部会话元数据，时间
范围（今天 / 7D / 30D / 90D，默认今天）与来源筛选、会话数 / 总 Tokens / 成本 / 平均时长
四张汇总卡、倒序列表（窄窗卡片行、宽窗表格、刷新有遮罩）、行点击查看 Token 拆分与按模型
明细、分页与 web 同款（范围摘要 / 页码 / 每页条数）、CSV 导出弹系统保存对话框并默认
保存到桌面（可自选目录，成功提示带完整路径）；成本按模型定价估算（与 web 会话页同口径）。页头新增「分享卡片」：本机用量
一键生成特刊 / 小票 / 霓虹 / 唱片四种海报，可复制图片或保存 PNG 到下载目录（热力图为
本机口径并跟随顶部周期）。窗口重启后保留上次的大小、位置与最大化状态（显示器已拔掉时
自动回到居中）。监控盘的「最近会话」小卡由会话视图接替，连同设置里的开关一并移除；
设置「网页」组新增「落地页」入口（token-usage.cc，无需配对）。「总计」视图下「总 Tokens」
标签旁加一个说明图标，悬停/聚焦显示口径：桌面只统计本机采集器队列的全部历史，web 端还
包含其他设备与更早的服务器侧记录，两边数字不必一致（这也解释了本机 39.92 亿 vs 网页
156 亿）。修复手动「检查更新」恒报失败：更新
清单改由滚动的 `desktop-latest` Release 提供（此前 CLI 发版抢占了仓库的 latest 端点），
尚无清单时提示「尚未发布更新清单」而非失败。修复会话列表「详情」列被裁（表格改自动
布局）。重装或升级后若托盘图标消失，仍需对安装目录的 exe 重打 High 完整性级别
（见 desktop-plan §11）。

## 0.2.1

2026-11-10。第二轮验收修正：三张构成卡不再重复「今日 / 近 7 天」（周期只由上方筛选
表达）；设置「网页」组四钮补 web 侧栏同款图标（仪表盘 / 项目 / 会话 / 成就）；采集操作卡
的 CLI 版本 Chip 点击即可探测 npm 最新版，并在旁边显示「最新 / 可更新 / 检查失败」；
底部脚注收敛为「主机名 #machineId 前 8 · © 2026 Token Usage」；修复 CLI 自报版本带 `v`
前缀时显示成 `vv0.5.4` 的问题。

## 0.2.0

2026-11-10。用量构成视图：新增「今日 / 近 7 天」周期切换（默认近 7 天、重启保留），
同时作用于来源构成、主要模型、项目与仓库三张卡；新增「主要模型」Top 5（行首带厂商 Logo，
与 web 仪表盘一致；其余合并为一行）与「项目与仓库」Top 5（同一仓库的多行项目已合并，
已确认的仓库显示 GitHub 入口，底部给出已归因占比）；顶部单值卡收敛为两格，待上传量与
队列体积并入同步卡，并新增「更新于」时间与手动刷新（读取期间按钮转圈、至少可见 0.4 秒）；
已配对的机器可从项目卡与设置里的「网页」组直达 web 的仪表盘 / 项目 / 会话 / 成就页
（未配对不显示入口）。页头主题按钮旁新增 GitHub 仓库入口；在托盘点「立即同步 / 暂停·
恢复」时，窗口内的按钮与数据会同步更新。

## 0.1.0

2026-11-10。首个 Windows 安装包发布。托盘伴生监控台：本机采集视角的今日/近 7 天
tokens、来源构成、同步状态与队列积压；一键同步 / Doctor / 对账 / 暂停恢复；配对
向导；每日汇总与故障提醒通知、免打扰时段；开机自启、单实例、浅/深/系统三态主题。
内置自动更新（Ed25519 签名校验，GitHub Releases 分发）。
